# 이오덕 《우리글 바로쓰기》 한글 검수 기준 및 치환 사전 (`ko-rules.md`)

이 문서는 이오덕 《우리글 바로쓰기》 핵심 원칙을 한글 문서와 UI 문구 검수에 바로 쓸 수 있도록 정리한 규칙집이자 치환 사전이다.
한글 초안·기술 문서·안내문·화면 문구를 다듬을 때 아래 기준과 치환 표를 차례대로 대조한다.
단, 프로젝트 규칙에서 정한 공식 도메인 용어·코드 식별자·법령/약관 고유 용어는 함부로 바꾸지 않는다.

---

## 1. 6대 핵심 원칙

1. **번역투·외래 어법 걷어내기**: 영어·일본어 문장 틀을 그대로 옮긴 조사(`~의`, `~에 있어서`, `~에 의하여`), 접미사(`-적`), 억지 무생물 주어, `가지다` 남용, 불필요한 복수 `-들`, 겹과거(`~했었다`)를 덜어낸다.
2. **피동(수동) 표현을 능동 표현으로 바꾸기**: `-되다`, `-어지다`, `-케 되다` 남발과 이중 피동(`보여지다`, `나뉘어지다` 등)을 걷어내고 행동 주체가 드러나는 능동문이나 자연스러운 자동사로 쓴다.
3. **명사화·관료투 버리고 동사·형용사로 생생하게 쓰기**: 움직임이나 상태를 `-기`, `-음`, `-함`, `~화(化)`나 추상 한자 명사(`진행`, `수행`, `발생`, `실시` 등)로 굳히지 않고 동사·형용사로 풀어쓴다.
4. **어려운 한자어·굳은 공문서 투를 쉬운 우리말로 바꾸기**: 권위를 내세우거나 굳어진 한자어를 읽는 사람이 한눈에 알아듣는 쉬운 우리말로 바꾼다.
5. **과잉 높임·사물 높임 바로잡기**: 사물·절차·상태에 선어말어미 `-시-`를 붙이는 잘못된 높임을 버리고, 사람(사용자)을 높일 때만 어법에 맞는 높임말을 쓴다.
6. **겹말·군더더기 빼고 입말처럼 자연스럽게 쓰기**: 뜻이 겹치는 말과 빈 수식어를 덜어내고, 소리 내어 읽었을 때 막힘없이 뜻이 통하는 문장으로 다듬는다.

## 2. 번역투·외래 어법 치환 사전

### 2.1 관형격 조사 `~의`와 접미사 `~적(的)` 치환 표

| 피할 표현 (번역투·추상 표현) | 다듬은 표현 (자연스러운 우리말) | 다듬는 요령 |
| :--- | :--- | :--- |
| `문제의 해결을 위한 방안` | `문제를 풀 방안` | 명사+`의`+명사를 목적어+서술어로 풀어쓴다 |
| `비밀번호의 변경` | `비밀번호 바꾸기` / `비밀번호 변경` | 불필요한 `의`를 빼거나 동사형으로 바꾼다 |
| `데이터의 손실이 발생할 수 있습니다` | `데이터를 잃을 수 있습니다` / `데이터가 사라질 수 있습니다` | `의`를 빼고 주술 관계로 고친다 |
| `지속적인 관리` | `꾸준한 관리` / `꾸준히 돌보기` | `-적인`을 고유어 관형사로 바꾼다 |
| `자동적으로 저장됩니다` | `자동으로 저장합니다` / `저절로 저장됩니다` | `-적으로`에서 `-적`을 덜어낸다 |
| `필수적인 항목` | `꼭 필요한 항목` / `필수 항목` | `-적인`을 빼거나 쉬운 말로 풀어쓴다 |
| `효율적인 처리를 위해` | `빠르고 정확하게 처리하려고` | 막연한 `-적` 대신 실제 상태를 또렷하게 적는다 |
| `일시적인 오류` | `잠깐 생긴 오류` | `-적인`을 쉬운 관형절로 바꾼다 |
| `구체적인 내용` | `자세한 내용` | 한자어+`-적인`을 쉬운 형용사로 바꾼다 |
| `전반적인 검토` | `전체 검토` / `두루 살피기` | `-적인`을 덜어낸다 |

### 2.2 번역투 조사·연결어 치환 표

| 피할 표현 (영어·일본어 직역) | 다듬은 표현 (자연스러운 우리말) | 비고 |
| :--- | :--- | :--- |
| `~에 있어서(서)` | `~에서` / `~할 때` / `~에는` | 일본어 `~に於いて`·영어 `in` 번역투 |
| `~에 의하여(의해)` | `~로` / `~가` / `~때문에` | 영어 `by` 수동태 번역투 |
| `~에 관하여(관해)` / `~에 대하여(대해)` | `~을/를` / `~을 두고` / `~에서` | 영어 `about` / `regarding` 번역투 |
| `~을 통하여(통해)` | `~로` / `~를 거쳐` / `~에서` | 영어 `through` 남용 번역투 |
| `~로부터` | `~에서` / `~에게서` | 영어 `from` 번역투 (시간·출발점은 `~부터`) |
| `~로 인하여(인해)` | `~때문에` / `~로` / `~탓에` | 굳은 번역·공문서 투 |
| `~에도 불구하고` | `~는데도` / `~지만` / `~아도/어도` | 연결 어미로 간결하게 이어 쓴다 |
| `~에 다름 아니다` | `~와 같다` / `~나 마찬가지다` | 일본어 `~にほかならない` 직역 |
| `~하기 위해(서)` (남발) | `~하려고` / `~하러` | 목적 어미 `-(으)려고`가 훨씬 자연스럽다 |
| `~할 수 있도록 한다` | `~하게 한다` / `~할 수 있게 돕는다` | 사역·우회 번역투 제거 |

### 2.3 무생물 주어·`가지다`·복수 `-들`·겹과거 치환 표

| 피할 표현 | 다듬은 표현 | 이유 |
| :--- | :--- | :--- |
| `본 업데이트는 성능을 개선합니다` | `이번 업데이트로 성능이 빨라집니다` | 무생물 주어를 부사어로 돌린다 |
| `이 문서는 설정 방법을 설명합니다` | *(서문 삭제)* 또는 `여기서는 설정 방법을 다룹니다` | 불필요한 서문 및 무생물 주어 제거 |
| `관심을 가지다` | `관심을 두다` / `마음을 쓰다` | 영어 `have an interest` 번역투 |
| `의미를 가지다` | `뜻이 있다` / `중요하다` | 영어 `have a meaning` 번역투 |
| `영향을 가지다` / `영향을 미치다` | `영향을 주다` | 자연스러운 우리말 동사 사용 |
| `권한을 가지다` | `권한이 있다` | 우리말 존재 표현(`있다`)이 자연스럽다 |
| `학생들이 파일들을 제출했습니다` | `학생이 파일을 제출했습니다` (또는 `학생들이 파일을 냈습니다`) | 사물 명사에 붙인 불필요한 `-들` 제거 |
| `이전에 설정했었던 값` | `이전에 설정한 값` | 번역투 과거완료(`-었었-`)를 `-었-/-ㄴ`으로 정리 |

## 3. 피동(수동)·이중 피동 → 능동 치환 사전

| 피할 표현 (피동·이중 피동) | 다듬은 표현 (능동·자연스러운 자동사) | 분류 |
| :--- | :--- | :--- |
| `보여지다` | `보이다` / `보여 주다` | 이중 피동 (`보-` + `-이-` + `-어지다`) |
| `불리워지다` | `불리다` / `부르다` | 이중 피동 |
| `생각되어지다` | `생각하다` / `여겨지다` | 이중 피동 |
| `잊혀지다` | `잊히다` / `잊다` | 이중 피동 |
| `마련되어지다` | `마련하다` / `마련되다` | 이중 피동 |
| `나뉘어지다` | `나누다` / `나뉘다` | 이중 피동 (`나누-` + `-이-` + `-어지다`) |
| `믿어지다` / `믿겨지다` | `믿다` / `믿기다` | 불필요한 피동·이중 피동 |
| `쓰여지다` | `쓰다` / `쓰이다` | 이중 피동 |
| `열려지다` / `닫혀지다` | `열리다` / `닫히다` (또는 `열다` / `닫다`) | 이중 피동 |
| `풀려지다` | `풀리다` / `풀다` | 이중 피동 |
| `변경 사항이 저장되어집니다` | `변경 사항을 저장합니다` / `바꾼 내용을 저장했습니다` | 이중 피동 → 능동 |
| `파일이 삭제되었습니다` | `파일을 지웠습니다` / `파일을 삭제했습니다` | 행위 주체가 분명할 때는 능동문으로 쓴다 |
| `과태료가 부과될 수 있습니다` | `과태료를 물 수 있습니다` / `과태료를 부과합니다` | 책임 회피형 피동을 명확한 서술어로 바꾼다 |
| `접수가 완료되었습니다` | `접수했습니다` | 명사화 + 피동 결합 제거 |

## 4. 명사화·관료투 → 동사·형용사 치환 사전

| 피할 표현 (명사화·관료투) | 다듬은 표현 (동사·형용사 중심) | 핵심 원칙 |
| :--- | :--- | :--- |
| `검토 진행 후 결과 안내 예정` | `검토한 뒤 결과를 알려 드립니다` | `진행`, `예정`을 빼고 동사로 풀어쓴다 |
| `데이터 초기화 수행` | `데이터를 초기화합니다` | 추상 동작 명사 `수행` 삭제 |
| `점검 실시` / `교육 실시` | `점검합니다` / `교육합니다` | 추상 동작 명사 `실시` 삭제 |
| `대회 개최가 예정되어 있습니다` | `대회를 엽니다` / `대회를 열 예정입니다` | `개최` + 피동 제거 |
| `새로운 기능 도입` | `새 기능을 넣었습니다` / `새 기능을 씁니다` | 동사로 풀어쓴다 |
| `네트워크 오류 발생 시 재시도 요망` | `네트워크 오류가 나면 다시 시도해 주세요` | `발생 시`, `요망`을 조건절·청유형으로 바꾼다 |
| `승인 처리가 완료되었습니다` | `승인했습니다` | `처리`, `완료되었습니다` 군더더기 삭제 |
| `파일 업로드가 필요합니다` | `파일을 올려야 합니다` / `파일을 올려 주세요` | 명사구 주어 대신 동사 서술어로 쓴다 |
| `수정이 불가능합니다` | `고칠 수 없습니다` / `수정할 수 없습니다` | `명사+불가능하다`를 `동사+-ㄹ 수 없다`로 바꾼다 |
| `확인 후 회신 바람` | `확인하고 답장해 주세요` | 공문서식 명사 종결을 자연스러운 문장으로 바꾼다 |

## 5. 어려운 한자어·공문서 투 → 쉬운 우리말 치환 사전

| 피할 표현 (굳은 한자어·공문서 투) | 다듬은 표현 (쉬운 우리말) |
| :--- | :--- |
| `미입력 시` / `미선택 시` / `미착용 시` | `입력하지 않으면` / `고르지 않으면` / `쓰지 않으면` |
| `우천 시` / `유사시` / `비상시` | `비가 오면` / `위급할 때` / `비상일 때` |
| `금일` / `명일` / `익일` / `작일` | `오늘` / `내일` / `다음 날` / `어제` |
| `향후` / `차후` / `추후` | `앞으로` / `다음에` / `나중에` |
| `가급적` | `되도록` |
| `유선 문의` / `내방` | `전화 문의` / `방문(찾아오기)` |
| `수령하다` / `지참하다` / `구비하다` | `받다` / `가져오다` / `갖추다` |
| `취합하다` | `모으다` |
| `상기 내용` / `하단 버튼` | `위 내용` / `아래 버튼` |
| `기존` / `신규` | `이전(원래)` / `새` |
| `소요되다` (`10분 소요`) | `걸리다` (`10분 걸립니다`) |
| `열람하다` | `열어 보다` / `보다` |
| `기재하다` | `적다` / `쓰다` |
| `고지하다` / `통보하다` | `알리다` / `알려 드리다` |

## 6. 과잉 높임·사물 높임 교정 사전

| 피할 표현 (사물 높임·과잉 높임) | 다듬은 표현 (어법에 맞는 높임) | 이유 |
| :--- | :--- | :--- |
| `주문이 접수되셨습니다` | `주문을 접수했습니다` | 주문은 사물이므로 `-시-`를 쓰지 않는다 |
| `결제가 완료되셨습니다` | `결제를 마쳤습니다` / `결제했습니다` | 결제에 `-시-`와 이중 피동을 쓰지 않는다 |
| `할인이 들어가십니다` / `적용되십니다` | `할인해 드립니다` / `할인을 받으십니다` | 할인 대신 사용자를 높이거나 `드리다`를 쓴다 |
| `파일이 업로드되셨습니다` | `파일을 올렸습니다` | 파일은 높임 대상이 아니다 |
| `문제가 있으신 경우` / `문의 사항이 있으신 경우` | `문제가 있으면` / `궁금한 점이 있으면` | 문제·문의 사항에 `-시-`를 붙이지 않는다 |
| `환불이 진행되실 예정입니다` | `환불해 드릴 예정입니다` / `환불합니다` | 환불 절차에 `-시-`를 붙이지 않는다 |

## 7. 겹말·군더더기 삭제 사전

| 피할 표현 (겹말·빈 수식어) | 다듬은 표현 |
| :--- | :--- |
| `미리 예약하다` / `미리 예매하다` | `예약하다` / `예매하다` (`예(豫)`에 이미 `미리` 뜻 포함) |
| `다시 재검토하다` / `다시 재시도하다` | `다시 검토하다` / `다시 시도하다` (또는 `재검토하다` / `재시도하다`) |
| `기간 동안` / `시간 동안` | `기간에` / `동안` |
| `약 10분 정도` / `대략 5개 내외` | `10분쯤` / `5개 안팎` (추정 표현 중복 제거) |
| `가장 최선의 방법` / `최고의 정점` | `가장 좋은 방법` (`최선`) / `꼭대기` (`정점`) |
| `함께 공유하다` | `나누다` / `공유하다` |
| `첫 시발점` | `출발점` / `첫걸음` |
| `내부 안쪽` / `외부 바깥` | `안쪽` / `바깥` |
| `매우 다양한` / `상당히 효율적으로` | 정확한 수치나 사실을 적고 빈 수식어는 뺀다 |
